# Rename Meetings without old-path aliases

A Meeting title edit may rename its canonical folder. Stillmatter will update workspace and stored references it controls rather than retain an alias at the old path, because the user wants one canonical Meeting location and references that reflect its current name. Required title review uses the same no-alias rename path. A Recording Bundle must name the canonical doorway exactly; a symlink at an old path does not authorize stale media references. Older aliases are not a substitute for migrating controlled references.

External links copied outside the workspace cannot be rewritten and may break, so the UI must warn before renaming. Rename is unavailable while that Meeting's Jobs are active, and reference updates must avoid leaving a partially renamed Meeting.
